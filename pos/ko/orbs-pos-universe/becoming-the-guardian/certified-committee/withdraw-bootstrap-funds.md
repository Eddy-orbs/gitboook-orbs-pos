# 지원 자금 수령 방법

검증자 노드를 운영하고 인증 절차를 거쳐 인증 위원회에 참여하는 가디언은 연간 총 3,000 DAI를 받을 수 있습니다. 이 펀드는 인증 위원회 참여를 유인해 해당 위원회의 참여 스테이킹을 늘리고, 앱 사용자에게 네트워크를 더 매력적으로 만들며, 운영 비용 절감을 보전합니다.

## Metamask 연결

* 트랜잭션 가스에 쓸 ETH가 있는 지갑으로 Metamask에 로그인합니다.
* Orbs FeesAndBootstrap 컨트랙트를 열고 Write Contract 탭으로 이동합니다 \[[https://etherscan.io/address/0xda7e381544Fc73cad7D9E63C86e561452b9B9E9C#writeContract](https://etherscan.io/address/0xda7e381544Fc73cad7D9E63C86e561452b9B9E9C#writeContract)]
* Connect to Web3를 눌러 Metamask를 연결합니다.

[![연결 안 됨](https://github.com/orbs-network/validator-instructions/raw/master/public/_img/wallet_not_connected.png)](https://github.com/orbs-network/validator-instructions/blob/master/public/_img/wallet_not_connected.png)

* Metamask를 선택합니다.

## 적립된 지원 펀드 인출

* 18. withdrawBootstrapFunds를 펼칩니다.

<div align="left"><figure><img src="../../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure></div>

* 가디언 주소를 입력하고 Write를 클릭합니다.
* Metamask에서 트랜잭션을 승인합니다.
* 부트스트랩 잔액(DAI)이 지갑으로 전송됩니다
