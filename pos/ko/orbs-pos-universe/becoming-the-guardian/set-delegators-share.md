# 위임자 몫 설정

각 가디언은 위임자에게 돌아가는 보상 비율을 조정할 수 있습니다.

기본값은 66.667%로, Orbs 스테이킹 프로토콜이 적립하는 전체 보상의 ⅔입니다. 즉 위임자는 스테이킹한 ORBS에 대해 연 6.667% APR을 받게 됩니다.

이 비율을 바꾸려면 가디언 지갑으로 [가디언 포털](https://guardians.orbs.network/)에 로그인합니다.

## ORBS 가디언 포털

[가디언 포털](https://guardians.orbs.network/)에서 `DELEGATORS SHARE` 탭을 선택합니다.

1. `Delegators share` 입력란에 새 숫자를 입력합니다.

{% hint style="warning" %}
비율은 0% 이상 66.667% 이하여야 합니다. 노드 운영 비용을 감안해 가디언이 노드를 운영하도록 유인하기 위해 최댓값이 66.667%로 제한되며, 이는 가디언 보상으로 최소 33.33%가 보장됨을 의미합니다.&#x20;
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure></div>

2. `ACCEPT` 버튼을 클릭합니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure></div>

3. 연결된 Metamask 지갑에서 트랜잭션 요청을 확인합니다.



{% hint style="info" %}
참고:

이 비율 설정은 [TETRA](https://staking.orbs.network/)에서 위임자에게 공개됩니다.
{% endhint %}
