# 위임자 되기

## 1. 지갑 준비

[Metamask](https://metamask.io/) 등 본인 지갑을 만들고 로그인합니다. 지갑은 이더리움과 ERC20 토큰을 지원해야 합니다.

## 2. TETRA(Orbs 스테이킹 지갑) 열기

* PC: Chrome 브라우저에서 [TETRA](https://staking.orbs.network/)를 엽니다.
* 모바일: TETRA 모바일 앱을 설치합니다. ([Android](https://play.google.com/store/apps/details?id=com.orbs.pos.klip) / [iOS](https://apps.apple.com/kr/app/tetra-mobile/id6453168712?l=en-GB))

TETRA에 지갑(예: Metamask)을 연결합니다.

## 3. ORBS 스테이킹

1. 거래소 등에서 ORBS 토큰을 이 지갑으로 보냅니다.
2. 스테이킹 중 승인 등에 쓸 가스비로 ETH를 보냅니다.
3. Metamask를 Tetra에 연결합니다.&#x20;
4. "STAKE" 버튼을 누르고 안내에 따릅니다.
   1. 위임할 가디언을 선택합니다.
   2. 스테이킹 컨트랙트로의 토큰 전송을 승인합니다.
   3. 스테이킹 컨트랙트 함수를 실행합니다.

{% hint style="info" %}
ORBS 언스테이크에는 14일 쿨다운이 필요합니다.
{% endhint %}
