# Set delegators share

Each guardian can adjust distributing rewards ratio for his/her delegators.

Default is 66.667% which is ⅔ of all rewards accumulated by orbs staking protocol. This means that delegators will receive 6.667% APR of their staked ORBS.

To change this rate, guardian need to login [Guardians Portal](https://guardians.orbs.network/) with guardian's wallet.

## ORBS Guardians Portal

Select `DELEGATORS SHARE` tab at [Guardians Portal](https://guardians.orbs.network/).

1. Input new number in `Delegators share` box.

{% hint style="warning" %}
The percentage must be between 0% and 66.667%. To incentivize guardians running node and cover the node operating cost, maximum value is restricted to 66.667%. This guarantees 33.33% as guardians rewards.&#x20;
{% endhint %}

2. Click `ACCEPT` button.

3. Confirm transaction request at connected Metamask wallet.



{% hint style="info" %}
NOTE:

This rate setting is disclosed to delegators at [TETRA](https://staking.orbs.network/)
{% endhint %}
